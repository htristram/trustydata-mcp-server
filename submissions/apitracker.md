# APITracker submission kit

Target: **apitracker.io** — MCP directory with an API-first audience.

## Steps

1. There is no submit form on apitracker.io (the only form is a Tally beta
   waitlist, which does not create a listing). The directory is curated by
   Apideck: request a listing by email at `apitracker@apideck.com`.
2. Include the metadata below in the message.

## Listing metadata

| Field | Value |
|---|---|
| **Name** | TrustyData |
| **Server URL** | `https://mcp.trustydata.app/mcp` |
| **API docs** | https://trustydata.fr/docs/ |
| **Pricing** | https://trustydata.fr/tarifs |

**Description (API angle — developer audience)**

> TrustyData's REST API for French address quality, company lookup (SIRENE) and
> catchment-area statistics (INSEE), real-estate sale prices (DVF) and
> establishment counts by activity (SIRENE) and business failures (BODACC), exposed natively over MCP.
> Same endpoints, same official data (BAN/INSEE/IGN/OSM), two access modes:
> REST for production pipelines, MCP for LLM-driven exploration and one-off
> enrichment. Transparent pricing from €0 to €149/month, no lock-in.
